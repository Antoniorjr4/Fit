# Milestone 1 acceptance criteria

- [ ] BLE adapter available on native Windows or Linux.
- [ ] Scan finds the Fit 3 (device name may be absent).
- [ ] Record manufacturer ID, advertised service UUIDs and RSSI.
- [ ] Establish a BLE connection without resetting the device.
- [ ] Enumerate services and characteristics.
- [ ] Review logs for private identifiers before sharing.

A scan alone does not prove the device is connectable or that proprietary Samsung data is accessible.
